# Windows 浏览器复验

此脚本用真实 Chrome 或 Edge，通过界面将一条未发送的聊天草稿转为本地委托。玩家让主理人独立交稿，先后邀请两名顾问，只选择第二位顾问的一条建议，修订、验收，再刷新页面，从地图重新进入委托田核对记录。

在 Windows 上准备 Node.js 22 或更高版本、可运行 AI_World 的 Python 3 和 Chrome 或 Edge。使用 AI_World 仓库根目录作为工作目录。

```powershell
node .\platform\evidence\harness-handoff-20261124\host-r2\browser-smoke.mjs (Get-Location).Path "$env:TEMP\ai-world-validation"
```

省略参数时使用当前目录和系统临时目录。可通过 `HARNESS_BROWSER_PATH` 或 `HARNESS_PYTHON_PATH` 指定可执行文件。脚本启动仅监听本机的临时村庄服务，使用空模型配置、初始三名居民和独立的临时浏览器配置。退出码为 0 时，界面操作、磁盘存档、刷新后的详情、所选提示、空聊天记录和空模型账本均已通过核对。
