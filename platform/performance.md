# 赛题村庄启动与画面性能

2026-11-20 在同一台 Windows 主机的 WSL Ubuntu 中测试。各次使用相同 x-kernel 内核、Wayland 原始盘、Chromium、QEMU 8.2.2 和 AArch64 Cortex-A76，保持 4 vCPU、2 GiB、纯 TCG。基线是本仓库提交 `07afcb8`。各轮创建新的客体 Chromium 配置和独立测试存档。暖缓存指宿主机复用已准备的只读启动盘。

| 指标 | 原版 | 只换网页与服务 | 完整优化，首次建盘 | 完整优化，复用启动盘 |
| --- | ---: | ---: | ---: | ---: |
| 启动到 QMP 可用 | 16.91 秒 | 10.80 秒 | 12.80 秒 | 0.15 秒 |
| 启动到 Weston 就绪、调用 Chromium | 20.93 秒 | 13.64 秒 | 15.90 秒 | 3.02 秒 |
| 启动到 QMP 抓到村庄地图 | 123.32 秒 | 80.67 秒 | 84.79 秒 | 72.08 秒 |
| 浏览器导航到村庄发出可玩事件 | 68.28 秒 | 37.58 秒 | 37.86 秒 | 39.08 秒 |
| 首屏素材传输量 | 34.54 MB | 2.29 MB | 2.29 MB | 2.29 MB |
| 进入后 8 秒内的帧回调间隔 P95 | 346 ms | 92 ms | 83 ms | 154 ms |

QMP 每秒采样一次画面，首帧数字包含这部分观测粒度。帧回调 P95 来自刚进入地图的短窗口，代表慢帧的量级，完整优化两次采样为 83–154 ms。此表记录本机工程对照，赛题指定页的正式性能多轮测量沿用其独立流程。

另用 GTK 图形窗口复测，启动至地图 74.39 秒，导航至可玩 39.74 秒。该轮首次页面请求发出前已过去 14.18 秒，服务器回包起始仅相差 48 ms，浏览器到 DOM 可交互还需约 11 秒。余下耗时主要集中于客体 Chromium 的冷启动、文档加载和渲染初始化。额外试跑的 HTTP 图片预取将大图下载提前，实际可玩时间却由 39.74 秒变为 44.82 秒，因此最终版本沿用按需请求。

## 优化内容

- 旧启动器每次复制 2 GiB raw 文件再在副本上安装会话脚本。现在首次建立本地只读缓存，后续直接复用，客体运行时用临时写入层。缓存位于 Linux 用户目录，避免客体持续从 Windows 挂载盘读取。
- 首屏原来需要解码整套原始 PNG 和两个后续场景，还在 Chromium 中裁切、缩放并重新编码窗口皮肤。TCG 使用提前裁好的图集与 WebP，议事厅和东林按需加载，脚本并行下载并按依赖顺序执行。HTTP/1.1 复用连接，减少 QEMU 转发时启动 `nc` 的次数。
- TCG 地图缓存背景投影，主要重绘居民、作物和环境动态的局部区域。打开界面时停掉背后持续重画的地图，任务和库存仍可更新。相机移动时随输入刷新。宿主 Chrome 软件渲染的 4 秒对照中，晴天地图整图复制从 30 次减到 5 次，打开委托窗或暂停时从 30 次减到 0 次。
- 状态接口先截取最近 100 条账本，再复制和返回，缩短大存档下的轮询。在 5,000 条模拟账本的宿主对照里，返回内容一致，快照中位耗时从 19.78 ms 降到 0.49 ms。

## 复现

启动入口见 [赛题平台说明](README.md)。应用测速可以临时用 `python3 platform/profile_village.py --port 18769` 代替常规宿主服务，再从另一个终端运行 `python3 platform/qemu_demo.py launch --port 18769 --headless`。探针输出 `VILLAGE_PROFILE`，包含导航、素材、帧回调和画布测量，并使用临时存档。可用 `--source` 指向旧版本的工作目录读取旧版资源。素材用 `python platform/build_tcg_assets.py` 从原图重建，需要 Pillow，玩家运行时无需安装 Pillow。

原始数据见 [原版](evidence/performance-20261120/baseline.json)、[仅应用优化](evidence/performance-20261120/app-only.json)、[组合冷缓存](evidence/performance-20261120/combined-cold.json)、[组合暖缓存](evidence/performance-20261120/combined-warm.json)、[GTK 图形窗口复测](evidence/performance-20261120/combined-gui.json) 和 [图片预取试跑](evidence/performance-20261120/preload-gui.json)。
