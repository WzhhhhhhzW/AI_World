# 六款形象接入说明

输入是用户提供的六人合图，顺序为上排ChatGPT、Claude、Grok，下排DeepSeek、Gemini、豆包。

- 使用方式：**内置 imagegen 编辑模式**，背景提取，`transparent_background=true`。未使用CLI付费API或读取用户密钥。
- 原图副本：`web/assets/avatars/residents-six-reference.png`。
- 项目使用的透明合图：`web/assets/avatars/residents-six-static.png`，1024×1536 RGBA。
- 图集分区：`web/assets/avatars.json`。前端先缓存各人物的独立透明区域，避免相邻人物头发/武器串入，不改写PNG文件。
- 功能：创建时六选一，选择保存在居民的`appearance`字段；地图立绘与资料头像一致，模型服务可以单独选择。已有居民也能在资料里更换外观。
- 当前是正面静态立绘，位移时仍显示静态图，不声称已经具备侧背面、走路或工作帧。后续需求见`村民动态形象美术要求.md`。

本次内置工具的完整提示词：

```text
Use case: background-extraction. Edit target: the supplied six-character village avatar sheet. Produce ONE transparent PNG atlas, same portrait aspect ratio and exact 3-column by 2-row character order as the original: top row white/lavender horned girl, orange-haired book-holding girl, blonde black-and-gold axe girl; bottom row blue-haired maid, purple-haired cat wizard, brown-haired woman in plain black clothes. Remove ONLY the cream background, all six nameplates and their text, decorative exclamation/sparkle marks floating outside the characters, and all floor shadows. Keep the exact six character designs, faces, poses, clothing, colors, accessories, wings and held items; do not redesign or add any characters. Keep complete full bodies including horns, weapon and shoes. Keep each character entirely inside its own equal-sized grid cell with generous transparent gutters and consistent foot baseline per row. Transparent pixels between all characters and around each silhouette; no white matte, no checkerboard drawn into the image, no words, no boxes, no scenery. This is a reusable game sprite atlas, static front-facing artwork only; do not invent walking frames.
```
